# App Privacy (App Store Connect) — answers, mapped from `SquareOff/Resources/PrivacyInfo.xcprivacy`

**Do you or your third-party partners collect data from this app?** Yes.
**Tracking** (NSPrivacyTracking): No. No tracking domains. No third-party SDKs are bundled.

| Data type | Collected | Linked to the user | Used for tracking | Purposes |
| --- | --- | --- | --- | --- |
| Contact Info › Email Address | Yes (account sign-up / sign-in, password reset, optional in feedback) | Yes | No | App Functionality |
| Contact Info › Name | Yes (display name; first/last name optional) | Yes | No | App Functionality |
| Identifiers › User ID | Yes (account id; an anonymous guest id for signed-out play) | Yes | No | App Functionality |
| User Content › Gameplay Content | Yes (moves, scores, results, replays) | Yes | No | App Functionality |
| User Content › Other User Content | Yes (feedback text) | Yes | No | App Functionality |

Not collected: precise or coarse location, physical address, phone number, health, financial info, contacts, photos, audio, browsing or search history, purchases, advertising data, crash or performance diagnostics, device id.

**Accessed API types** (manifest): UserDefaults, reason CA92.1 (the app's own settings only).

**Processors named in the privacy policy** (not SDKs): hosting in the EU, Resend (transactional email), Cloudflare Turnstile (sign-up form only), Apple / Google / GitHub when chosen for sign-in.
